# Progress Tracking (Generic)

## When
Thread has multiple messages (always for >1 turn).

## Capabilities
- Compress old messages: key points, goal, what is done, structure progress
- Write `progress.md` to workspace root, read on next turn
- Keep context compact, human-like

## Workspace
- File: `progress.md` at `ai-notes-xyz-agent-workspace/shell/agent/{threadId}/progress.md`
